# History

Evidence and superseded numbers, kept for the record and never as reference
([RULES](../../RULES.md) `history-is-not-reference`). The Symphony passes this folder over when it
reads documents.

- [The board that went back on 2026-11-12](board-went-back-2026-11-12.md) — the consuming
  project's store recovered by hand, the first time the procedure in
  [A board that went back](../TASKS.md#a-board-that-went-back) was followed, with that day's numbers.
- [The client's first visits, move by move](client-first-visits.md) — what each change of the
  client did to the pages' first visits, as its guide's Budget recorded them until every page kind
  had moved to the React client.
- [The owner's words](owner-words.md) — the owner's words the guides and the documents quoted as
  the basis of a rule or a choice, word for word, each with its date and where it stood.
