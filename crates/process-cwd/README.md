# process-cwd

The working directories of running processes, read through `lsof`, for sweeps that must leave a tree some process still stands in; and children whose pipes no other thread's child can hold open, started without a fork on macOS (elsewhere by std's spawn), with an async wait that kills the child if the wait is dropped. Unix only.

One of the helpers of Symphony, a document, review and task workspace. Each helper has a version of its own, from 1.0.0: a release that breaks a name it exports is a new major version, and any other change is a minor or a patch.
