# symphony-api

Symphony's wire types: the JSON its server sends and its client reads, serde only, so one definition builds for the server and for wasm32. Its block vocabulary is what a plugin renders to, re-exported by `symphony-plugin`.

Part of [Symphony](https://github.com/heavenstudio/symphony)'s plugin kit, with `symphony-plugin` and `symphony-docs`, the three at one version. At 0.1.0 the kit promises no name yet: it takes 1.0.0 once its block vocabulary has left the app's wire types in `symphony-api` ([RELEASES](https://github.com/heavenstudio/symphony/blob/main/docs/RELEASES.md#packages-on-cratesio)).
