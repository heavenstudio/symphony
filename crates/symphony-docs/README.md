# symphony-docs

A project's documents as its docs build checks them, and the Markdown syntax every reader of them shares: lines, headings and anchors, fences, links, components, and card lines with their entries. `check` runs the generic checks and a project's own `DocCheck`s over one reading and names each reference that does not resolve by its `file:line`.

Part of [Symphony](https://github.com/heavenstudio/symphony)'s plugin kit, with `symphony-plugin` and `symphony-api`, the three at one version. At 0.1.0 the kit promises no name yet: it takes 1.0.0 once its block vocabulary has left the app's wire types in `symphony-api` ([RELEASES](https://github.com/heavenstudio/symphony/blob/main/docs/RELEASES.md#packages-on-cratesio)).
